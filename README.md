# Cardápio semanal web

Aplicação responsiva em JavaScript com duas páginas:

- `/`: visualização pública, com destaque para o cardápio do dia.
- `/admin`: edição protegida por senha e sessão.

## Executar localmente

1. Instale o Node.js 18 ou superior.
2. Abra a pasta do projeto no terminal.
3. Execute `npm install`.
4. Defina as variáveis de ambiente abaixo ou use os valores de demonstração.
5. Execute `npm start`.
6. Acesse `http://localhost:3000`.

Variáveis de exemplo:

```text
PORT=3000
ADMIN_PASSWORD=uma-senha-forte
SESSION_SECRET=uma-chave-longa-e-aleatoria
```
